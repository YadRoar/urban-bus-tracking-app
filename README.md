# urban-bus-tracking-app
🚌 Real-Time Urban Bus Tracking Mobile Application for Senior Project

## 📌 Overview

Final Graduation Project: Design and Development of a mobile application for real-time tracking of urban buses.

The objective of this project was to develop a solution that allows users to visualize bus locations, routes, schedules, and transportation information through a mobile application, improving accessibility and user experience in public transportation.

---

## 🚀 Features

- Real-time bus location tracking using GPS.
- Interactive maps and route visualization.
- Bus schedules and route information.
- Fare information.
- QR/NFC payment integration concept.
- User-friendly mobile interface.
- Transportation data management.

---

## 🏗️ Architecture

The solution was designed using a mobile application architecture integrated with backend services and external APIs.

Components:

- Mobile Application
- Backend API
- Database
- GPS Location Services
- Mapping Services
